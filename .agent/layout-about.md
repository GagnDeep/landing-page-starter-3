# Layout Documentation: About Page

- **Intent**: Tell the story of the salon, its founders, and its commitment to quality. Establish emotional connection.
- **Rhythm**:
  - Hero: Atmospheric image, large serif heading ("Our Story").
  - Content block: 2-column layout (text + image) detailing the origin.
  - Team section: Grid of key staff members.
  - Philosophy/Values: Icon + text list highlighting luxury, hygiene, and convenience.
  - Final CTA: "Experience it yourself" -> link to booking.
