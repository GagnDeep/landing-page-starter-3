# About Page Layout Structure

1. **Hero**: Hero image of Dr. Gaurav and team, strong mission statement.
2. **Our Story**: Timeline or narrative of the clinic's founding and growth.
3. **Core Values**: Grid of 3-4 core values (Empathy, Excellence, Hygiene, Technology).
4. **Meet Dr. Gaurav**: Detailed bio, credentials, philosophy.
5. **The Team**: Grid of staff profiles.
6. **Clinic Tour**: Gallery of the facility.
7. **CTA**: Book a consultation.
