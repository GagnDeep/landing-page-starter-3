# About Page Layout Blueprint

## 1. Hero / Header
- **Layout Intent:** Minimal header with a large, editorial serif title.
- **Visual Rhythm:** Focus on typography rather than background image. Soft, muted background.

## 2. Our Story
- **Layout Intent:** Split 50/50 layout (Text left, Image right).
- **Visual Rhythm:** Paragraphs in clean sans-serif. Image of the founders or the early salon days.

## 3. The Philosophy
- **Layout Intent:** Centered text block with large quote.
- **Visual Rhythm:** High contrast, deep background. Serif font for the quote.

## 4. Team / Founders
- **Layout Intent:** 2 or 3 column grid for portraits.
- **Visual Rhythm:** Clean, gallery-style layout with subtle hover effects.
