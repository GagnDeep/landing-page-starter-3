# Layout: FAQ Page Blueprint

A purely utilitarian but beautifully typeset page for quick answers.

1. **Hero Section:** "How can we help?" with a search bar.
2. **Category Jump Links:** Quick links to "Appointments", "Billing", "Treatments", "Emergencies".
3. **Accordion Lists:** Grouped by category. Smooth, satisfying open/close animations.
4. **Still have questions?:** A block pointing to direct contact methods (Phone, WhatsApp, Email).
