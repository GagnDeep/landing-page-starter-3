# FAQ Page Layout Architecture

## 1. Hero Section (`faq-hero`)
- **Intent:** Set a helpful, transparent tone.
- **Rhythm:** A simple, clean header ("Frequently Asked Questions").

## 2. Category Navigation (`faq-categories`)
- **Intent:** Help users find specific answers quickly.
- **Rhythm:** A sticky sidebar or a top horizontal menu linking to different sections (e.g., "Booking", "The Day Of", "Deliverables").

## 3. FAQ Section: Booking & Logistics (`faq-booking`)
- **Intent:** Answers about securing the date, contracts, etc.
- **Rhythm:** An accordion layout under a clear heading.

## 4. FAQ Section: The Wedding Day (`faq-day-of`)
- **Intent:** Answers about the process on the actual day.
- **Rhythm:** An accordion layout.

## 5. FAQ Section: Post-Production & Deliverables (`faq-deliverables`)
- **Intent:** Answers about editing timelines, albums, etc.
- **Rhythm:** An accordion layout.

## 6. Still Have Questions? (`faq-contact-prompt`)
- **Intent:** Catch-all for unanswered queries.
- **Rhythm:** A small, friendly block linking directly to the contact page.

## 7. Final CTA (`faq-cta`)
- **Intent:** General inquiry prompt.
- **Rhythm:** Standard high-contrast CTA block.
