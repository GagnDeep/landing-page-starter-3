# FAQ Page Layout Architecture

## Section 1: Header (`FAQ Title`)
- **Intent:** Set expectations.
- **Rhythm:** Simple centered title.

## Section 2: Categories (`Quick Links`)
- **Intent:** Jump to specific question types (Booking, Preparation, Aftercare).
- **Rhythm:** Row of anchor links.

## Section 3: Question List (`Accordions`)
- **Intent:** Provide answers concisely.
- **Rhythm:** Stacked accordion components, grouped by category. Smooth expansion animation.

## Section 4: Still have questions? (`Contact Teaser`)
- **Intent:** Catch-all for unresolved queries.
- **Rhythm:** Centered text with a button linking to the Contact page.
