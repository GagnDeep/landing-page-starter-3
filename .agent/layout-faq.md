# FAQ Page Layout Blueprint

1. **Hero Header:** Page title "Frequently Asked Questions".
2. **Search Bar:** A prominent search input to find specific questions quickly.
3. **Category Navigation:** Links to jump to sections (e.g., General, Treatments, Billing, Appointments).
4. **Section: General & Appointments:** Accordion list of questions.
5. **Section: Treatments & Procedures:** Accordion list of questions.
6. **Section: Billing & Insurance:** Accordion list of questions.
7. **Still Have Questions?:** Contact block with phone number and email.
