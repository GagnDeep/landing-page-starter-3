# FAQ Page Layout Intent

**Page Intent:** Resolve common anxieties and logistical questions.

## Sections
1. **`FAQHero`**: Simple, reassuring header.
2. **`SearchFAQ`**: Prominent search bar to find answers quickly.
3. **`CategorizedAccordions`**: Sections for "Appointments", "Pain & Comfort", "Billing", and "Treatments".
4. **`StillHaveQuestions`**: Contact block linking to the contact page or phone number.
