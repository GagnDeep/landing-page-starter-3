# FAQ Layout Blueprint

## Goal
Address common patient concerns systematically to reduce friction before booking.

## Sections
1. **Hero Section:** "Frequently Asked Questions."
2. **Search Bar:** Simple input to filter questions instantly.
3. **Category Navigation:** Jump links for "General", "Dental Procedures", "Aesthetics & Injectables", "Billing & Insurance".
4. **Accordion List - General:** Expanding panels for general clinic info (hours, parking).
5. **Accordion List - Dental:** Expanding panels for dental-specific worries (pain management, recovery times).
6. **Accordion List - Aesthetics:** Expanding panels for aesthetics (bruising, longevity of results).
7. **Contact Prompt:** "Still have questions?" Box linking to contact page or providing a phone number.
