# Dentocare FAQ Page Layout

## 1. Hero Section
- **Layout:** Clean title "How can we help?" with a search bar.
- **Rhythm:** Instantly helpful.

## 2. Category Navigation
- **Layout:** Sidebar or sticky top menu to jump between General, Billing, Treatments.
- **Rhythm:** Organized.

## 3. General Questions
- **Layout:** Accordion list.
- **Rhythm:** Scannable.

## 4. Treatment-Specific Questions
- **Layout:** Accordion list segmented by treatment type.
- **Rhythm:** Scannable.

## 5. Billing & Insurance Questions
- **Layout:** Accordion list.
- **Rhythm:** Scannable.

## 6. Still Have Questions? (Contact CTA)
- **Layout:** Friendly prompt to call or email the clinic.
- **Rhythm:** Supportive.
