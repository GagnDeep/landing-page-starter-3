# Features (Services/Academy) Layout Blueprint

## 1. Hero
- **Layout Intent:** Standard text header.
- **Visual Rhythm:** Large title "Our Offerings" or similar.

## 2. Feature Matrix
- **Layout Intent:** Alternating left/right split sections.
- **Visual Rhythm:** Image on one side, text/list on the other. Soft backgrounds.

## 3. CTA
- **Layout Intent:** Full width colored banner.
- **Visual Rhythm:** Bold, primary color background encouraging booking/enrollment.
