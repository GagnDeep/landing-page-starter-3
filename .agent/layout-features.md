# Features / Services Page Layout Intent

**Page Intent:** Detailed index of all clinical services provided, organized by category.

## Sections
1. **`ServicesHero`**: Clean header defining comprehensive care.
2. **`ServiceCategoryNav`**: Sticky internal navigation (General, Cosmetic, Restorative, Ortho).
3. **`GeneralDentistrySection`**: List of general services with descriptions.
4. **`CosmeticDentistrySection`**: Focus on aesthetics (veneers, whitening).
5. **`RestorativeDentistrySection`**: Focus on function (implants, crowns).
6. **`OrthodonticsSection`**: Focus on alignment (braces, clear aligners).
7. **`ServicesFAQ`**: Specific questions regarding treatments.
8. **`ServicesCTA`**: Book a specific consultation.
