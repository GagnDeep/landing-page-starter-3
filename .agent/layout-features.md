# Features (Services Overview) Layout Blueprint

## Goal
Provide a comprehensive, easily navigable index of all services offered, categorized logically between dental and aesthetics.

## Sections
1. **Hero Section:** Simple, elegant typographic hero. Headline: "Bespoke Treatments & Services".
2. **Category Navigation / Filters:** Sticky or prominent sub-nav allowing users to jump between "Advanced Dentistry", "Facial Aesthetics", and "Bridal Packages".
3. **Advanced Dentistry Section:**
    - Sub-categories: General, Cosmetic (Veneers, Whitening), Restorative (Implants), Orthodontics (Clear Aligners).
    - Grid layout with icons or subtle imagery for each service.
4. **Facial Aesthetics Section:**
    - Sub-categories: Injectables (Botox, Fillers), Skin Rejuvenation (Peels, Microneedling), Anti-Aging.
    - Grid layout matching the dentistry section.
5. **Bridal Packages Section:** Highlighted banner or special card layout detailing bundled services for brides.
6. **Technology Highlight:** Brief section reiterating the advanced tech used for these features.
7. **Final CTA:** "Not sure what you need? Book a Discovery Consultation."
