# Layout Documentation: Services / Features Page

- **Intent**: Detailed breakdown of every service category offered.
- **Rhythm**:
  - Hero: Clean header with a brief intro.
  - Sticky Side Nav: Allows users to jump between categories (Hair, Skin, Nails, etc.).
  - Content Sections: Large heading per category, followed by a list of specific treatments, descriptions, and a "Book Now" button for each.
  - Bottom CTA.
