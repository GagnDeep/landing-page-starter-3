# Pricing Layout Blueprint

## 1. Header
- **Layout Intent:** Centered header text.
- **Visual Rhythm:** Clear, simple typography.

## 2. Pricing Tables
- **Layout Intent:** 3-column layout.
- **Visual Rhythm:** Cards with borders. Elevated middle card. Clean numbers.

## 3. Comparison / Details
- **Layout Intent:** Table or accordion list.
- **Visual Rhythm:** Structured, highly readable data.
