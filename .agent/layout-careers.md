# Layout: Careers Page Blueprint

To attract top-tier dental professionals and staff.

1. **Hero Section:** "Join the Smile Saviors Team."
2. **Culture & Values:** Why work here? Focus on the premium environment, continuing education, and patient-first approach.
3. **Benefits:** Grid highlighting perks (Health, PTO, Training, Modern Equipment).
4. **Open Positions:** An accordion or list view of current openings (e.g., Associate Dentist, Hygienist, Front Desk).
5. **Application Process:** Simple steps on how to apply.
6. **General Application Form:** If no specific roles are open, a way to drop a resume.
