# Layout Documentation: Careers/Academy Page

## Structural Intent
This page serves a dual purpose: recruiting talent for the salon and recruiting students for the academy. The layout needs to project authority, growth, and a rigorous but rewarding environment.

## Section Details

### 1. Hero
- **Layout:** High-energy image of the team or a class in session. Bold typography ("Learn from the Best" / "Join Our Team").
- **Rhythm:** Inspiring, expansive.
- **Intent:** Set an aspirational tone.

### 2. Two Paths (Split Section)
- **Layout:** Two distinct columns or stacked full-width sections separating "Salon Careers" from "Academy Courses".
- **Rhythm:** Clear division, high contrast.
- **Intent:** User segmentation based on intent.

### 3. Why Amil's? (Benefits/Values)
- **Layout:** A grid of icons or short text blocks detailing benefits (mentorship, environment, growth).
- **Rhythm:** Quick, punchy, scannable.

### 4. Open Positions / Course Schedule
- **Layout:** A clean list or table of available roles or upcoming courses.
- **Rhythm:** Structured, utilitarian.

### 5. Application/Enrollment CTA
- **Layout:** Prominent form or button linking to an application process.
