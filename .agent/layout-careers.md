# Careers Page Layout Architecture

## 1. Hero Section (`careers-hero`)
- **Intent:** Inspire potential talent.
- **Rhythm:** A vibrant, behind-the-scenes image with an inviting headline ("Join Our Team").

## 2. Culture & Values (`culture`)
- **Intent:** Explain what it's like to work at the studio.
- **Rhythm:** A 2-column text block or a small grid highlighting aspects of the work environment.

## 3. Open Roles (`open-roles`)
- **Intent:** List available positions.
- **Rhythm:** A clean list or accordion of current openings (e.g., "Second Shooter", "Editor"). If none, a message encouraging general applications.

## 4. Application Process (`application-process`)
- **Intent:** Explain how to apply.
- **Rhythm:** Clear, step-by-step instructions.

## 5. Final CTA (`careers-cta`)
- **Intent:** Link to a general application form or email address.
- **Rhythm:** Standard CTA block.
