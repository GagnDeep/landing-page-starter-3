# Layout Blueprint: Careers Page
**Status:** Defined (Phase 1)
**Vibe:** Professional, Growth-oriented, Warm Team Culture

## Sections
1. **Hero:** "Join Our Team" - image of the staff.
2. **Why Work With Us?:** Benefits, culture, work-life balance (Icon grid).
3. **Open Positions:** List or accordion of current job openings (e.g., Dental Assistant, Receptionist).
4. **Application Process:** Brief steps on how to apply.
5. **General Application Form:** If no specific roles are open.
