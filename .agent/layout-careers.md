# Careers Page Layout Architecture

## Section 1: Header (`Careers Title`)
- **Intent:** Invite talent to join the team.
- **Rhythm:** Inspiring hero image with a bold headline.

## Section 2: Why Join Us (`Benefits`)
- **Intent:** Sell the workplace culture.
- **Rhythm:** 3-column grid highlighting perks (Training, Environment, Growth).

## Section 3: Open Positions (`Job Listings`)
- **Intent:** List available roles.
- **Rhythm:** Stacked list of roles. Clicking expands to show details and a "Apply" button.

## Section 4: Application Form (`Apply Now`)
- **Intent:** Streamline applications.
- **Rhythm:** Clean form allowing resume uploads.
