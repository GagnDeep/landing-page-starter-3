# Blog / Patient Resources Page Layout Blueprint

1. **Hero Header:** Page title "Patient Resources" or "Dental Insights".
2. **Featured Article:** Large highlight of the most recent or important blog post.
3. **Category Filters:** Tags to sort articles (e.g., Oral Hygiene, Cosmetic, Implants, Clinic News).
4. **Article Grid:** A responsive grid of blog post cards (image, title, excerpt, date).
5. **Pagination / Load More:** Controls for browsing older posts.
6. **Newsletter Sign-up:** "Subscribe for dental tips and clinic updates."
