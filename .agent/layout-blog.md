# Blog Layout Blueprint

## 1. Featured Post
- **Layout Intent:** Large top card.
- **Visual Rhythm:** Prominent image, large serif title.

## 2. Post Grid
- **Layout Intent:** 3-column grid for standard posts.
- **Visual Rhythm:** Clean cards, standard spacing.

## 3. Pagination / Load More
- **Layout Intent:** Centered button or pagination links.
- **Visual Rhythm:** Simple, minimal UI.
