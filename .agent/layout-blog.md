# Blog Page Layout Intent

**Page Intent:** Dental health education, clinic news, and SEO-driven content.

## Sections
1. **`BlogHero`**: Featured latest article with a large image and excerpt.
2. **`CategoryFilters`**: Pill navigation to filter by topic (Oral Hygiene, Cosmetic, Clinic News).
3. **`ArticleGrid`**: 3-column responsive grid of post cards.
4. **`NewsletterSignup`**: Clean, inline block to subscribe for dental tips.
