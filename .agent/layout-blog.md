# Blog Page Layout Architecture

## Section 1: Header (`Blog Title`)
- **Intent:** Introduce the salon's journal/blog.
- **Rhythm:** Elegant header, optionally highlighting a featured post.

## Section 2: Featured Post (`Hero Post`)
- **Intent:** Draw attention to the most important or recent article.
- **Rhythm:** Large image with an overlapping text card containing the title and excerpt.

## Section 3: Article Grid (`Recent Posts`)
- **Intent:** Display all articles.
- **Rhythm:** 3-column grid of article cards (Image, Date, Title, "Read More").

## Section 4: Categories (`Filter`)
- **Intent:** Allow users to find specific topics (e.g., Hair Care, Nail Trends).
- **Rhythm:** Horizontal list of tags below the main header.

## Section 5: Newsletter Signup (`Subscribe`)
- **Intent:** Capture audience.
- **Rhythm:** Clean banner at the bottom of the page.
