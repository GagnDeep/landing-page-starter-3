# Contact Page Layout Architecture

## Section 1: Header (`Contact Title`)
- **Intent:** Welcome the user to reach out.
- **Rhythm:** Clean, large typography.

## Section 2: Contact Form (`Form`)
- **Intent:** Capture inquiries.
- **Rhythm:** Left side: Clean, spacious form fields. Right side: Contact info (Phone, Email, Socials).

## Section 3: Location Details (`Map & Address`)
- **Intent:** Help users find the salon.
- **Rhythm:** Large embedded map showing the Sector 17 location. Address and parking instructions overlaid or alongside.

## Section 4: Hours (`Opening Times`)
- **Intent:** Clearly state availability.
- **Rhythm:** Simple, centered table or list of days and hours.
