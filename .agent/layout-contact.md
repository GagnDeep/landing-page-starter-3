# Layout Blueprint: Contact Page
**Status:** Defined (Phase 1)
**Vibe:** Accessible, Prompt, Welcoming

## Sections
1. **Hero:** "We'd love to hear from you."
2. **Split Layout (Main):**
    - *Left:* Contact Information (Phone, Email, Physical Address, Hours).
    - *Right:* Contact Form (Name, Email, Phone, Subject, Message).
3. **Interactive Map:** Large embedded map showing the clinic location and parking info.
4. **Emergency Info Block:** Highlighted section for out-of-hours emergencies.
