# Contact Page Layout Architecture

## 1. Hero Section (`contact-hero`)
- **Intent:** Welcoming and direct.
- **Rhythm:** A clean header ("Let's Connect" or "Inquire").

## 2. Contact Information (`contact-info`)
- **Intent:** Provide alternative ways to reach out (email, phone, studio address if applicable).
- **Rhythm:** A clean, perhaps sidebar or top-aligned section with clear details.

## 3. The Inquiry Form (`contact-form`)
- **Intent:** The primary conversion point. Needs to feel premium, not like a generic web form.
- **Rhythm:** A spacious, well-styled form asking for essential details (Names, Date, Venue, Message). Use elegant input fields (e.g., bottom borders only, or soft backgrounds).

## 4. Response Expectation (`response-time`)
- **Intent:** Set expectations.
- **Rhythm:** A small, polite note near the submit button (e.g., "We aim to respond to all inquiries within 48 hours.").

## 5. Social Proof/Reassurance (`contact-testimonial`)
- **Intent:** A final nudge of confidence while they fill out the form.
- **Rhythm:** A single, powerful quote placed near the form.
