# Contact Page Layout Architecture

## 1. Page Header
- **Visuals:** Standard header.
- **Content:** "Get in Touch / Visit Us".

## 2. Contact Information
- **Visuals:** Grid of icons and text.
- **Content:** Phone, Email, Address, WhatsApp link.

## 3. Operating Hours
- **Visuals:** Simple list or table.
- **Content:** Daily hours, emergency protocols.

## 4. Contact Form
- **Visuals:** Clean form fields.
- **Content:** Name, Email, Phone, Preferred Date, Message, Submit Button.

## 5. Interactive Map
- **Visuals:** Full width or large embedded Google Map.
- **Content:** Pin pointing the clinic location in Patiala.
